# v0.9 — Scripting, ObsiScript & Native

**Tag:** `v0.9.0` · **Date:** 2026-09-28 · **Scope:** scripting · obsiscript · native

A full scripting layer: the custom ObsiScript language (lexer → parser → AST → type
checker → interpreter with closures, classes and modules), a sandboxed script host with
lifecycle + hot reload for JavaScript and ObsiScript, and a native extension system with
FFI/ABI marshaling, capability gating and WASM modules.

## What's inside

- **@obx/obsiscript (17 tests)** — `Lexer`/`tokenize` (keywords incl. `and`/`or`/`not`,
  escapes, errors with positions), `Parser`/`parse` (declarations, control flow, classes,
  functions, imports/exports, `spawn`), AST, `typeCheck` (annotation checking with
  issues), `Interpreter` (closures, recursion, `this` binding on methods, arrays/maps,
  builtins, native calls, line-aware `RuntimeError`s, `BreakpointHit` debugger hooks),
  `Scheduler` (spawned tasks by time), `ModuleLoader` (exports, cache, circular-import
  detection), `runModule`.
- **@obx/scripting (11 tests)** — `Sandbox` (identifier scanning, `SandboxViolation`),
  `JavaScriptEngine` (allowlisted bindings injected as identifiers, live exports,
  init/update/dispose lifecycle), `ObsiScriptEngine` (host api + persistent `state` bag),
  `ScriptHost` (register/load/init/update/reload/dispose, dependency order + circular
  detection, phase/error hooks, stats), hot reload preserving state, `generateDts`
  (.d.ts emission), `validateApi` (functions + NativeFunction objects), `makeHost`.
- **@obx/native (8 tests)** — `parseSignature` ("i32(i32,i32)" style ABI), `NativeAbi`
  (define/call with i32/i64/f32/f64/string/ptr marshaling), `generateCHeader` +
  `generateRustBindings`, `ExtensionRegistry` (platform + capability gating, lifecycle,
  ABI exposure), `WasmModule`/`WasmInstance` (magic/version validation, compile+
  instantiate, export calls, memory views).
