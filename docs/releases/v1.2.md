# OBX Engine v1.2.0 — GPU Rendering Foundation

**Release date:** 2026-09-29
**Theme:** GPU Rendering Foundation — backend-independent `GraphicsDevice`, three GPU backends, software rasterizer, shader system with caching
**Tests:** 601 green (53 files) | **Packages:** 42 lockstep @ 1.2.0 | **Baseline:** v1.1.0 + `docs/ROADMAP-1.9.md`

## Overview

The second roadmap milestone delivers the rendering foundation: a single backend-independent
`GraphicsDevice` API with three working implementations — **WebGPU**, **WebGL2** and a full
**software rasterizer** — plus a shader compiler (OBX declaration grammar, WGSL and GLSL
reflection), variant-aware shader caching, and explicit GPU resource lifetime management.
The software backend remains fully functional and pixel-exact under test, preserving the
headless/deterministic execution guarantee.

## What's New

### `@obx/graphics` — Device Layer (`graphics/src/device.ts`)

One API surface implemented by every backend (Rule 5):

- **GraphicsDevice** — `createBuffer`, `createTexture`, `createSampler`, `createShader`,
  `createPipeline`, `createCommandList`, `createFence`, `submit`, `stats`, `destroy`
- **GpuBuffer / GpuTexture / Sampler / Pipeline / Fence** — typed handles with `destroyed`
  state and idempotent `destroy()`; use-after-destroy throws `GraphicsError`
- **CommandList** — `begin(target, clear)` → `setViewport` / `setPipeline` /
  `setVertexBuffer(slot, …)` / `setIndexBuffer` / `setUniform` / `setTexture` /
  `draw(count, {firstVertex, instanceCount})` / `drawIndexed(count, {firstIndex, baseVertex, instanceCount})` / `end()`
  with strict state validation (begin/end/draw transitions are enforced)
- **DeviceStats** — buffers, textures, pipelines, shaders, draws, triangles, instances,
  bufferWrites, textureWrites, submits
- Formats: `rgba8`, `r8`, `depth32` (depth target) · vertex formats `float32x2/x3/x4` ·
  cull modes `back`/`front`/`none` · `triangle-list` topology

### Software Rasterizer (`graphics/src/software.ts`)

A complete reference rasterizer used for headless CI, tests and determinism:

- Vertex fetch with interleaved layouts (position/uv/normal + instance attributes),
  `uMvp` or `uModel*uView*uProj` transforms (column-major), near-plane w rejection
- Edge-function triangle rasterization with perspective-correct UV/color interpolation,
  depth test (`less`) + depth write, face culling, viewport mapping (y-down screen space)
- Texture sampling (nearest, `clamp`/`repeat` addressing) with atlas regions via UV
- Instanced drawing: `aInstancePos`, `aInstanceSize`, `aInstanceUv`, `aInstanceColor`
- Lambert shading (`uLightDir` × `aNormal`, ambient 0.3)
- Synchronous `submit()` playback returning an already-signaled fence

### WebGPU Backend (`graphics/src/webgpu.ts`)

- Full mapping onto a `GpuDeviceLike` seam (buffers with shadow CPU copies, textures with
  `createView()`, samplers, shader modules, render pipelines with vertex layouts and
  cull/depth state, command encoders, queue submission)
- One-shot command-list semantics (re-submitting a list throws), fences via
  `queue.onSubmittedWorkDone()`
- WGSL shader sources only (validated)

### WebGL2 Backend (`graphics/src/webgl2.ts`)

- Full mapping onto a `WebGL2ContextLike` seam (`#version 300 es` shader compilation with
  error surfacing, program linking, VAO-less attribute setup with divisors, `drawArrays` /
  `drawElements`, framebuffer render targets, sync-object fences)
- GLSL shader sources only (validated); pipelines free their program on `destroy()`

### Shader System (`graphics/src/shaders.ts`)

- **ShaderCompiler** — three source languages with reflection (`uniforms`, `attributes`,
  `samplers`, entry points):
  - `obx` — declaration grammar (`uniform|attribute|varying <type> <name>`,
    `entry vertex|fragment <name>`)
  - `wgsl` — `var<uniform>`, `texture_2d<f32>`, `@location(n)` / `@vertex` / `@fragment`
  - `glsl` — `uniform`, `in`/`attribute`, `void main()`
- **Defines + variants** — compile-time substitution with stable variant keys (FNV hash)
- **ShaderCache** — acquire/has/evict/clear with hit/miss/size/eviction stats
- **ShaderCompileError** — source name + line number diagnostics
- **isCompiledShader** — structural type guard working across all backends

## Conventions (locked, tested)

- Front faces = counter-clockwise in NDC (negative screen-space area after y-flip);
  `cullMode: "back"` culls positive area
- Depth compare `less`, clear depth `1.0`; depth targets use `depth32`
- Matrix uniforms are column-major 16-float arrays; attribute names:
  `aPosition`, `aUv`, `aNormal`, `aInstancePos`, `aInstanceSize`, `aInstanceUv`, `aInstanceColor`
- Instance attributes live in vertex buffer slot 1 (or any non-zero slot)
- Vertex `arrayStride`/offsets must be 4-byte aligned (Float32Array views); indexed
  draws use `Uint16` indices

- **30 new tests** (601 total / 53 files): shader parsing for all three languages,
  variants, cache lifecycle, compile errors with line numbers; software rasterization
