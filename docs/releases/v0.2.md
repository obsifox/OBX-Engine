# v0.2 — ECS Architecture

**Tag:** `v0.2.0` · **Date:** 2026-09-28 · **Scope:** core · runtime · ecs · engine

Entity–Component–System done archetype-first, wrapped in a batteries-included
`World` facade.

## What's inside

- **@obx/ecs** — archetypes with cached queries (up to 3 components, with/without
  filters), deferred structural command buffer (no mid-iteration mutation hazards),
  entity relationships (parent/children), component event hooks (add/remove),
  world resources, `Builder` fluent entity factory, change polling (`Changed`).
- **@obx/engine** — `World` facade: `defineComponent/defineSystem/defineWorldResource`,
  scene tree queries (`queryScene`, `queryDescendants`, `queryAncestors`), system
  ordering (`before`/`after`/deps + DFS order validation), `TickPipeline`
  (process-first, stage caps), `WorldSerializer` (JSON + storage adapters,
  restore-new-entities), `SystemScheduler`, `spawn`.
- **Math layer preview** — `@obx/math` (Vec2/Vec3/Quat/Mat4/AABB/Color/Transform2D/3D)
  and the software rasterizer foundations land alongside.

## Tests

36 new tests green (ecs 27, engine 9) — archetype edge cases, query cache identity,
command buffer timing, ordering violations, serializer roundtrips (83 total with v0.1).
