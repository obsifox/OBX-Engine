# v0.3 — 2D Release + OBX Engine Identity

**Tag:** `v0.3.0` · **Date:** 2026-09-28 · **Scope:** math · rendering · input · scene · brand

The project gets its name, its face, and a complete 2D stack.

## What's inside

- **Identity** — the project migrates to **OBX Engine** (npm scope `@obx`); the editor
  concept is **ObsiFox Studio**. Authentic brand kit in `brand/`: fox-orange `#FF6A1A`,
  ember `#FFB020`, signal-cyan `#41E0FF`, on an obsidian `#0B0E14` base — logo, wordmark,
  hero fox, `brand.md` usage rules.
- **@obx/math** — `Vec2`/`Vec3`, `Quat`, `Mat4`, `AABB`/`Sphere`, `Color` (hex parsing,
  CSS strings), `Transform2D`, `Transform3D`.
- **@obx/rendering (2D)** — `SoftwareBackend` (deterministic quad rasterization),
  `SpriteBatcher`, `Texture`, `SpriteSheet` (regions, packing helpers, `uvRect`),
  `Camera2D` (zoom, rotation, screen↔world), `Renderer2D`, `encodePng` (RGBA-8 + CRC32),
  `Canvas2DBackend` browser adapter.
- **@obx/input** — `InputManager` with action/axis bindings (`ActionBinding`,
  `AxisBinding`), keyboard/mouse/touch state tracking (pressed/held/released edges),
  gamepad snapshots, `DomInputAdapter` for browsers.
- **@obx/scene** — transform components with hierarchy propagation
  (`Transform2D/3D` → `WorldTransform2D/3D`, `computeWorldTransform2D/3D`), frame
  interpolation (`getInterpolatedTransform2D`), `createTransformSystem2D/3D`,
  `Renderable3D` collection and `MeshRenderer3D` data.
