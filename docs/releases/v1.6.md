## What this is

Scope = roadmap `# 1.6.0` **Real Networking & Multiplayer**: upgrade the networking
simulation into real infrastructure — real transports (UDP/TCP/WebSocket/WebRTC
adapter), a network core (serializer, clock, channels, connection, sockets), a
multiplayer runtime (dedicated server, client, replication, snapshots), optimization
(prediction/reconciliation, interpolation, bandwidth budgeting) and a security layer
(session auth, encryption, rate limiting, input validation, server-side authority) —
delivered as orchestrated RUN-2026-000006 (type=feature) with baseline 756, composed
playbook, executable gates G0–G5 (all PASS) and a receipt.

## New modules (`networking/src/`, extended — Rule 1)

| Module | Contents |
| --- | --- |
| `serializer.ts` | `Writer`/`Reader` with bounds-checked `SerializerError`, u8/u16/u32/i32/f32/f64, varint + zigzag, length-prefixed bytes/strings, `encodeVarint`/`decodeVarint`, helpers |
| `clock.ts` | `NetworkClock` (RTT sampling `syncFromRtt`, averaged offset, `estimateServerTime`, `tickNumber`, tick-rate), generic `InterpolationBuffer` (delayed `sample` with caller lerp, `prune`) |
| `channel.ts` | `UnreliableChannel` (sequenced, drop-old), `SequencedChannel`, `ReliableStream` (frame kinds data/ack, pending resend with interval + maxResends, `flush`, `ack`, `receive`, stats sent/resent/dropped/duplicated) |
| `socket.ts` | `DatagramSocket` abstraction + in-memory datagram wiring |
| `connection.ts` | `Connection` state machine (HELLO/WELCOME/HEARTBEAT/DATA/CLOSE frames, stamp-based RTT, heartbeats, `invalidPackets` hardening — malformed frames dropped, never thrown) |
| `transports.ts` | `InMemoryNetwork` (deterministic drop/loss sampler + `setDropRate`), `NodeUdpTransport`, `NodeTcpTransport` + `TcpListener` (length-prefixed stream frames), `NodeWebSocketTransport` (RFC6455 handshake + masked client frames), `encodeStreamFrame`/`StreamFrameDecoder`, `encodeWebSocketFrame`/`decodeWebSocketFrames`, `websocketAcceptKey` (RFC sample vector verified), `WebRtcTransport` (channel attachment API; `open()` throws until a platform data-channel provider is injected) |
| `crypto.ts` | pure-TS `sha256` (FIPS vectors), `hmacSha256` (RFC4231 case 1), `chacha20Block`/`chacha20Xor` (RFC8439 §2.4.2), `sha1` (abc vector), `toHex`/`fromHex` |
| `security.ts` | `SessionAuthority` (HMAC-SHA256 session tokens: issue/verify/revoke, expiry + forge rejection), `RateLimiter` (token bucket with refill), `sealPacket`/`openPacket` (ChaCha20 + HMAC checksum envelope, tamper rejection, `NETWORK_MAGIC=0x4f42`), `InputValidator`, `AuthorityGuard` (client/host/server), `deriveKey`, `tokenFingerprint` |
