# v0.4 — 3D Engine

**Tag:** `v0.4.0` · **Date:** 2026-09-28 · **Scope:** rendering (3D) · scene (3D)

A full software 3D pipeline: meshes, materials, lighting, a z-buffered rasterizer,
glTF import and a deterministic `Renderer3D`.

## What's inside

- **Meshes** — `Mesh` + `RasterVertex` (position/normal/uv/color), `createCube`,
  `createUvSphere`, `createPlane`, `createQuadBuffer`, `computeNormals`,
  `composeWorldMatrix`, `transformAabb`.
- **Materials & textures** — `Material` (base color, emissive, metallic, roughness,
  opacity, textures), `Texture` from RGBA data.
- **Lighting** — `AmbientLight`, `DirectionalLight`, `PointLight`, `Fog`,
  `LightingEnvironment` via `createLighting`, Blinn-Phong shading through
  `ShadingContext`.
- **Camera3D** — look-at placement, pitch/yaw clamps, `viewMatrix`/`projectionMatrix`
  (right-handed Y-up, radians), world↔screen mapping.
- **Software3DBackend** — near-plane clipping, screen mapping, z-buffer, barycentric
  triangle setup with perspective-correct UVs, backface culling.
- **glTF** — `parseGltf` (JSON) and binary `.glb` input, `GltfModel`/`GltfNode`,
  `flattenGltf` scene flattening.
- **Renderer3D** — deterministic command buffer (draw/clear/present), per-frame
  `Renderer3DStats`, `Recording3DBackend` test double; `MeshRenderer3D` ECS bridge in
  `@obx/scene` (`addMeshRenderer3D`, `collectRenderables3D`).

## Tests

38 new green (rendering3d 34, mesh-renderer3d 4) — **191 total** at this release,
including pixel-exact rasterization cases and z-buffer occlusion proofs.
