# OBX Engine v1.3.0 — Asset & Scene Pipeline

**Release date:** 2026-09-29
**Theme:** Asset & Scene Pipeline — GUID asset database, 15 importers, dependency graph, scene/prefab system, hot reload
**Tests:** 637 green (58 files) | **Packages:** 43 lockstep @ 1.3.0 | **Baseline:** v1.2.0 + `docs/ROADMAP-1.9.md`

## Overview

The third roadmap milestone turns the existing asset records/index architecture
(`AssetRecord`/`AssetIndex` in `@obx/project`) into a complete production asset pipeline
in the new `@obx/assets` package: a GUID-based `AssetDatabase`, an importer pipeline with
15 built-in format importers, content-hash caching, a dependency graph with cycle
detection and cascade invalidation, a change watcher, production scene/prefab file
formats with versioned migration, and a hot-reload hub.

## What's New

### `@obx/assets` — Asset Database (`database.ts`)

- **AssetDatabase** — GUID ↔ path registry (`register`/`unregister`/`byGuid`/`byPath`/
  `query`), import pipeline (`import`/`importAll`), dependency graph
  (`dependenciesOf`/`dependentsOf`/`addDependency`/`detectCycle`), cascade
  `invalidate`, `serialize`/`restore`
- **AssetCache** — content-hash keyed cache with hit/miss/size/invalidation stats
- **AssetWatcher** — change notification (`notifyChange`) and hash-difference scanning
  (`scan`) with a `Signal<[AssetWatcherEvent]>` change stream
- **GUIDs** (`guid.ts`) — `createAssetGuid(seed?)` (deterministic from seeds, random
  otherwise), `isAssetGuid`, `contentHash`

### Import Pipeline (`importers.ts`)

`Source Asset → Importer → Intermediate Data → Processed Asset → Runtime Resource` —
`AssetImporter.import(context) → ImportedAsset { type, data, dependencies, metadata }`.
Custom importers register into `ImporterRegistry` by name and extension.

Built-in importers (honest support levels):

| Importer | Level | Output |
|---|---|---|
| `json` / `text` | FULL | parsed values, line counts |
| `png` | FULL | dimensions, bit depth, color type |
| `bmp` / `webp` | FULL | dimensions (VP8/VP8L/VP8X) |
| `jpg` | FULL | SOF frame dimensions |
| `svg` | FULL | width/height/viewBox |
| `wav` | FULL | channels, sample rate, bit depth (RIFF fmt walk) |
| `ogg` / `mp3` | PARTIAL | format metadata, ID3 detection |
| `gltf` | FULL | mesh/material/texture/animation counts + external URI dependencies |
| `glb` | FULL | container version + JSON-chunk counts |
| `obj` | FULL | v/vt/vn/f counts + `mtllib` dependencies |
| `ttf` / `otf` | FULL | sfnt table count, format detection |
| `fbx` | STUB | binary/ascii header + version only (tooling-dependent) |

### Dependency Tracking

- Dependency graph with direct `dependenciesOf`/`dependentsOf` edges
- `detectCycle(from, to)` — would-be cycle detection before adding edges
- Circular and self dependencies throw `AssetDatabaseError`
- Importer-reported dependencies (gltf buffers/images, obj mtllib) auto-register assets
- `invalidate(guid)` removes cache entries for the asset and its transitive dependents

### Scene Files (`scenes.ts`)

- `.scene`/`.prefab` JSON format (`SceneFile`) with `format`, `version`, `name`,
  `metadata`, `guidReferences`, `entities` (id/parent/components), `resources`
- `serializeScene`/`stringifyScene`/`parseScene`/`loadScene` over `@obx/ecs` worlds
- `validateScene` — duplicate ids, missing parents/roots, bad GUID references
- Versioned **migrations**: `registerSceneMigration({from, to, migrate})`, built-in
  v1→v2 upgrade, future versions tolerated

### Prefab System

- `prefabFromWorld` / `createPrefab` — prefab files with `prefabRoot` + `overrides`
- `instantiatePrefab(world, prefab, overrides)` — entity-id remapping (fresh indices),
  deep reference remapping (`entity`/`entities` fields in component data), prefab and
  call-site overrides merged per component
- `applyOverride` — replace-merge component values on live entities

### Hot Reload (`hotreload.ts`)

- `HotReloadHub` — typed reload kinds (`texture`, `material`, `shader`, `scene`,
  `script`, `audio`, `asset`), `register(kind | "*", handler)`, `notify`, per-GUID
  reload counts, event history, enable/disable
- `kindForExtension` — extension → kind mapping

## Tests & Demo

- **36 new tests** (637 total / 58 files): GUID determinism and validation; every
  importer against crafted binary fixtures (PNG/JPG/WEBP/BMP headers, RIFF WAVE, OggS,
  ID3/frame-sync MP3, glTF + GLB, OBJ + mtllib, TTF/OTF sfnt, FBX binary header);
  registry override/unregister; database import/cache/invalidation/cycle/watcher/
  serialization; scene round-trips with parent references, validation errors,
  migrations; prefab instantiation with id remapping and overrides; hot-reload routing
- **`examples/v130-demo`** — full pipeline: 11 assets across 7 importers, dependency
  auto-registration, cache hit/miss + cascade invalidation, scene round-trip (2
  entities), 3 prefab instances with overrides, 4 hot-reload events + watcher detection;
  renders a pipeline-stage visualization (`output/frame.png`, `output/stats.json`)
