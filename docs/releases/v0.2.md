# v0.2 — ECS Architecture

**Tag:** `v0.2.0` · **Date:** 2026-09-28 · **Scope:** ecs · engine

Entity–Component–System with archetype storage and generational entity ids, wrapped
in an `Engine`/`Application` runtime.

## What's inside

- **@obx/ecs** — `World` with archetype partitioning and cached `Query` objects
  (multi-component with/without filters), generational `Entity` ids
  (`entityIndex`/`entityGeneration`/`formatEntity`), `defineComponent`/`defineSystem`/
  `defineResource`/`defineWorldResource`, `Parent`/`Children` relationships,
  `SystemScheduler` with phases (`DEFAULT_PHASE`), world inspection (`WorldStats`,
  `EntityInspection`, `listComponentDefinitions`), world serialization
  (`SerializedWorld`, `LoadOptions`, restore-into-existing-world).
- **@obx/engine** — `Engine` and `Application` lifecycle around a `World`
  (`EngineConfig`, `DEFAULT_ENGINE_CONFIG`, `EngineEvents`).
- **Math + raster foundations** — `@obx/math` (Vec2/Vec3/Quat/Mat4/AABB/Color/
  Transform2D/3D) and the software rasterizer groundwork land alongside.

## Tests

36 new green (ecs 27, engine 9) — 83 total with the foundation suites. Covered:
archetype edges, query cache identity, entity generation safety, scheduler phases,
serialization roundtrips (the `ecs-demo` restores 3 entities exactly).
