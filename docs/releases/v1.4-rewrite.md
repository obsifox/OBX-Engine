## What this is

The fourth and final milestone of the orchestrated rewrite, scope = engine version
1.4 (ObsiFox Studio, `@obx/editor`). With this release the rewrite covers the full
sequence the assistant authored: v1.1 → v1.2 → v1.3 → v1.4, each milestone an
orchestrated run with baseline, composed playbook, executable gates, structured
findings and a receipt.

## Rewrite delta (behavior preserved)

| Module | Before | After |
| --- | --- | --- |
| editor core | `editor.ts` 707-line monolith | `core/`: model, document, commands, selection, inspector, transform, console, profiler, viewport, session (compatibility barrel kept at `editor.ts`) |
| infra | `infra.ts` 202-line compound | `infra/`: shortcuts, palette, preferences, layout |
| scenetools | `scenetools.ts` 220-line compound | `scenetools/`: gizmo, snap, camera |
| shell | `shell.ts` 263-line compound | `shell/`: docking, toolbar, statusbar |
| script editor | `scripteditor.ts` 410-line compound | `scripteditor/`: types, tokenizer, analysis, editor, paths |
| hierarchy, properties, project, browser, studio, index | focused modules | unchanged |

Behavior-preserving change included: module-level mutable counters (`nodeCounter`,
`tabCounter`) became `nextNodeId()`/`nextTabId()` accessors so state stays inside its
owning module (identical id sequences).

Public API preserved exactly (barrels re-export every previous symbol): scene core
(`Vec2`/`Vec3`/`SceneDocument`/commands/`Selection`/`Inspector`/`TransformTool`/
`EditorConsole`/`Profiler`/`Viewport`/`EditorSession`), studio facade (`ObsiFoxStudio`,
`STUDIO_NAME`), project manager, hierarchy, asset browser, extended inspector,
script editor (`tokenize`/`analyze`/`ScriptEditor`), docking/toolbar/status bar,
shortcuts/palette/preferences/layouts. Test sources untouched (79/79 editor tests).
