# OBX Engine — Brand Identity

## Products

| Product | Role |
|---|---|
| **OBX Engine** | The cross-platform game & application engine |
| **ObsiFox Studio** | The official editor & development environment (roadmap v0.8) |

## Logo

- `logo.svg` — primary mark: obsidian hexagon + geometric fox head
- `wordmark.svg` — horizontal lockup: mark + **OBX** ENGINE

The hexagon is the engine core; the fox is the builder spirit; the cyan
chevrons are the signal/circuit accents of a real-time system.

## Color system

| Token | Hex | Use |
|---|---|---|
| Obsidian | `#0B0E14` | Backgrounds, surfaces |
| Surface | `#1B2333` | Cards, panels |
| Fox Orange | `#FF6A1A` | Primary brand, actions |
| Ember | `#FFB020` | Gradients, highlights |
| Signal Cyan | `#41E0FF` | Tech accents, glows |
| Light | `#E8ECF2` | Primary text |
| Slate | `#8A94A6` | Secondary text |

## Typography

- Display / wordmark: heavy grotesque (Arial Black stack), wide tracking
- UI / docs: standard sans-serif stack
- Code: monospace

## Voice

Precise, fast, confident. Engine copy is technical and English-only.
Tagline: **One engine. Any platform.**

## Usage rules

- Keep clear space around the mark equal to one ear height
- Never recolor the fox outside the orange/ember gradient
- On light backgrounds use the full obsidian hexagon version
