## What this is

First feature milestone after the completed rewrite series (v1.1 → v1.4). Scope =
roadmap `# 1.5.0` **Production Graphics**: a full lighting/shading stack in
`@obx/rendering`, a VFX node-graph layer in `@obx/vfx`, deterministic CPU-reference
implementations of GPU-visible pipelines, and measurable rendering optimization —
delivered as orchestrated RUN-2026-000005 (type=feature, tier T3) with baseline,
composed playbook, executable gates G0–G5 and a receipt.

## New modules (`rendering/src/`, extended — Rule 1)

| Module | Contents |
| --- | --- |
| `lights.ts` | ambient/directional/point/spot/area lights, inverse-square attenuation with smooth range cutoff, spotlight penumbra falloff, area solid-angle scale, `evaluateLighting`, `LightRig`, `packLights` GPU uniform packing (stride 12, numeric kind codes) |
| `pbr.ts` | `PbrMaterial extends Material` (normal/AO/metallic-roughness textures, emission strength), GGX distribution, Smith geometry, Schlick Fresnel, `evaluateBrdf`, `shadePbr` with shadow factor + IBL + emission |
| `shadows.ts` | CPU reference shadow-map rasterizer, hard + PCF sampling, bias control, practical-scheme `cascadeSplits` (λ), `CascadedShadowMaps`, `orthographicLightViewProjection`, coverage helper |
| `environment.ts` | gradient + sun-disc `Sky`, `renderSky`, cube `ReflectionProbe` bake/sample, irradiance, IBL diffuse/specular/ambient, `environmentProbeFromSky` |
| `post.ts` | RGBA-float `FrameBuffer`, tone map (linear/reinhard/aces), bright-pass + blur bloom, color grade (exposure/contrast/saturation/lift/gamma/gain), vignette, FXAA, SSAO, depth of field, motion blur, TAA, `applyPostChain` |
| `culling.ts` | Gribb-Hartmann `Frustum.fromViewProjection`, AABB frustum culling, LOD selection, opaque/transparent sorting, coarse `OcclusionBuffer` + `occlusionCull`, `RenderQueue` with stats |
| `rendergraph.ts` | resource-declared `RenderGraph` with dependency-ordered compile, cycle detection (`RenderGraphError`), injectable-clock `execute`, `RenderGraphStats` + `measureBottlenecks` |
| `quality.ts` | low/medium/high/ultra presets (shadow size, PCF taps, cascades, max lights, bloom, particle budget), `scaledQuality`, `QualityController` |
| `gpuparticles.ts` | deterministic seeded `GpuParticleSystem` (spawn rate, lifetime, gravity, drag, emitter shapes), `ParticleGpuDevice` instance-buffer upload path (stride 8), `ParticleTrail`, `GpuEffectSystem` (turbulence/vortex) |

## Visualization

The milestone frame is a **real path-traced render produced by the v1.5 stack
itself** (`examples/v150-demo/src/render.js`): analytic sky + sun glow
(`skyRadiance`), 6 PBR materials (copper metal, pearl ceramic, mirror chrome,
matte navy, emissive, glossy red) shaded with `evaluateBrdf` + `lightRadiance`
against a 4-light rig with per-light ray-traced visibility, IBL fill from
`bakeProbeFromSky`, 1 reflection bounce with Schlick Fresnel, 2x2 supersampling,
then the real post chain (bloom → ACES → grade → FXAA → vignette).
