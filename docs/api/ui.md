# UI API

`@obx/ui` — retained widget tree with layout, themes and animation.

## Tree and layout

`UiNode` tree with `addChild`/`removeChild`; `FlexLayout` (row/column, gap, justify,
align) and anchor-based positioning.

## Widgets

`Label`, `Button`, `Checkbox`, `Slider`, `TextInput`, `Panel`, `ScrollView`, `Window`
(draggable, closable). `Theme` drives colors, fonts and metrics.

## Text and animation

Bitmap text with wrapping/alignment; `UiAnimator` tweens size/position/opacity with
easing functions.
