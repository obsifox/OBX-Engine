# v0.95 — Networking, Server Runtime, CLI & Build

**Tag:** `v0.95.0` · **Date:** 2026-09-28 · **Scope:** networking · server · cli · build

The Build & Advanced layer: a full networking stack (protocol profiles, simulated
transports with latency/jitter/loss, reliable channels, RPC, replication, prediction,
interpolation, lag compensation, interest management), a headless dedicated server
(config, logging, metrics, plugins, server scripts), the `obsifox` CLI with fourteen
commands, and a build system (graph, dependency analysis, bundling, asset compression,
cache, incremental rebuilds) exporting to five platform targets.

## What's inside

- **@obx/networking (12 tests)** — `protocolProfiles` (tcp/udp/websocket/webrtc/memory
  traits: ordered/reliable/framed), `Transport` + `MemoryNetwork`/`MemoryTransport`
  (deterministic seeded links with latency, jitter and drop rate), `encodePacket`/
  `decodePacket` (12-byte header codec with magic validation), `ReliableChannel`
  (sequence numbers, acks, retransmission with retry budget, ordered reassembly),
  `RpcSystem` (register/call, request-response correlation, unknown-method errors,
  timeouts), `ReplicationSystem`/`ReplicationClient` (tracked entities, patches,
  tick-stamped snapshots, stale-snapshot rejection), `PredictionSystem` (input history,
  server correction with replay of unacked inputs), `InterpolationSystem` (tick-buffered
  lerp sampling), `LagCompensation` (bounded history, rewind), `InterestManagement`
  (radius visibility + filtering), `GameServer`/`GameClient` (client/server architecture,
  server-authoritative input application via session binding, interest-filtered
  snapshot broadcast).
- **@obx/server (8 tests)** — `createServerConfig` (validated name/host/port/tickRate/
  maxClients/logLevel), `ServerLogger` (levels, capacity, sinks, filter), `ServerMetrics`
  (counters, gauges, uptime, snapshot), `ServerPluginHost` (lifecycle + message hooks
  with per-plugin error isolation), `ServerScriptHost` (server scripts with disable/
  enable), `HeadlessRuntime` (start/stop/step loop without rendering), `DedicatedServer`
  (config + logger + metrics + plugins + scripts + networking fused: connect/disconnect,
  broadcast, step, `status`).
- **@obx/cli (10 tests)** — `parseArgs` (commands, positionals, `--flag`, `--key=value`,
  short flags), `runCli` with injectable `CliHost` (in-memory file store), commands:
  `create` (project generator with 11 standard folders), `dev`, `editor`, `build`,
  `export` (windows/linux/android/web/server packages written to `dist/`), `run`,
  `test`, `clean`, `doctor` (diagnostics + engine compatibility), `assets`
  (list/check), `package`, `plugin` (list/check), `config` (get/set/list), `help`,
  `version`; exit codes 0/1/2.
- **@obx/build (11 tests)** — `BuildGraph` (nodes + edges, topological order with cycle
  detection, dirty marking, incremental rebuilds), `BuildCache` (hash-keyed hits/misses),
  `parseImports`/`analyzeDependencies` (module graphs + cycle reports), `bundleModules`
  (dependency-first module registry bundle), `processAssets`/`extractAsset` (packBits
  compression with base64 records), `optimizeCode`, `exportTarget`/`exportTargets`
  (windows/linux/android/web/server manifests with entry, runtime files and platform
  config), `BuildPipeline` (analyze → compile → bundle → assets → optimize → runtime →
  package → sign → release with checksums and cached optimization), `packageProject`,
  `hashContent`.
