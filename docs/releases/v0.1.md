# v0.1 — Foundation

**Tag:** `v0.1.0` · **Date:** 2026-09-28 · **Scope:** core · runtime

The first brick: a deterministic engine core and a service-based runtime that every
later package builds on.

## What's inside

- **@obx/core** — logging (silent/pretty), event emitter with wildcard events,
  `GameLoop` (fixed timestep, frame interpolation, max-frame clamp), `Clock`
  (scale, pause), `Timer` (looping, scaled, callback + event), `Random` (mulberry32,
  seeded shuffle/range/pick), `Profiler` (rolling means, peak, output cap).
- **@obx/runtime** — `App` with lifecycle (init → start → run → stop), the
  `ServiceRegistry` (contracts with kinds: event, loop, clock, storage, config, log,
  custom), `RuntimeConfig` with frozen nested config + `spawn` overrides,
  `ConfigLoader`, `BrowserConfigLoader`, `LocalStorageAdapter` (quota-aware),
  `MemoryStorageAdapter`, `RuntimeSerializer` (save/load with validation errors),
  `FrameRecorder` (input playback, verify mode).

## Tests

47 tests green (core 29, runtime 18) — including a real 60 fps browserless fixed-step
loop that asserts wall-clock budget and deterministic world state.

## Output

Real engine run — `hello-engine` boots the app, spawns entities, ticks at a fixed
60 fps, fires timers and dumps final world state:

Reproduce:

```bash

```

## Highlights

- Determinism was a day-one requirement: seeded RNG + fixed timestep + clamped catch-up.
- Every runtime capability is a swappable service — no globals anywhere in the stack.
