## Public Interfaces (v1.0.1)
- **Skill entry:** `SKILL.md` - mother skill
- **Commands:**
  - `./scripts/detect_env.sh [--json] [--out state.json]`
  - `./scripts/baseline.sh`
  - `./scripts/gate_check.sh <gate> [--no-run]`
  - `./scripts/secret_scan.sh`
  - `./scripts/dep_audit.sh`
  - `./scripts/report_lint.sh`
  - `./tests/gates.test.sh`
- **State:** `.eng/state.json` v1.0.0, `.eng/templates/`
- **Gates:** G0 Build, G1 Tests, G2 Lens, G3 Security, G4 Release

## Configuration Format (v1.0.1)
- `state.json` schema v1 with gates, tasks, evidence, risks, budget
- Lenses: markdown checklist + expected output
- Playbooks: markdown domain checklists
- No formal agent contracts yet
- No permission matrix
- No model routing (Tier only)

## State Model (v1.0.1)
- Single `.eng/state.json` per project
- No run isolation
- No event log
- No recovery
- No worktree isolation
- Evidence ledger in `.eng/evidence.md`

## Checkpoint Model (v1.0.1)
- Branch `eng/<task>-<date>` if git exists
- Else copy to `.eng/checkpoint/`
- No formal recovery/reconcile logic

## Gaps Identified vs v1.1 Spec

### Missing: Formal State Machine
- No canonical states INTAKE, BASELINE, CLASSIFICATION, etc.
- No transition rules with preconditions/postconditions
- Invalid transitions not rejected deterministically

### Missing: Run Manager
- No unique RUN-xxx ID
- No `.eng/runs/RUN-xxx/` isolation
- No manifest.json, events.jsonl, receipt.json

### Missing: Event Log
- No append-only event log
- No event categories RUN_CREATED, GATE_PASSED, etc.

### Missing: Agent Contracts
- Roles are lenses (checklists), not executable contracts with inputs/outputs/permissions/tools/model_policy
- No permission matrix

### Missing: Permission Matrix
- No least-privilege filesystem/shell/network/git/dependency/database/deployment/secret

### Missing: Model Routing
- Tier != Model distinction not implemented
- No adapter abstraction

### Missing: Playbook Engine
- WORK TYPE vs DOMAIN not separated
- No workflow types (feature, bug-fix, refactor, etc.)
- No domain overlays composition (base + overlay + risk + tier)

### Missing: Preview Mode
- No `eng preview` that shows classification without mutation

### Missing: Recovery System
- No resume/recover/reconcile
- No stale RUN detection

### Missing: Worktree Isolation
- No isolated execution per run
- No uncommitted changes detection

### Missing: Review/Rework Bounded Loop
- Loop cap exists (2 per gate) but not formal state machine with REWORK state

### Missing: Receipt
- No machine-readable receipt.json answering why tier/agents/gates selected

### Missing: Structured Knowledge
- Only lessons.md unstructured, no knowledge/lessons/failures/decisions/patterns/regressions

### Missing: Skill Registry
- No registry interface for built-in/project/external skills

### Missing: Skill Security
- No manifest validation, permission declaration

### Missing: Adapter Layer
- No claude/codex/copilot/generic adapters

### Missing: Evaluation Expansion
- Only 15 scenarios, need 50+ deterministic covering routing, delegation, security, recovery, verification, governance
