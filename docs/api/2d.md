# 2D API

`@obx/rendering` 2D path — `Renderer2D` over a `Rasterizer2D` backend.

## Backends

`SoftwareBackend(width, height)` with `clear(color)`, `readPixel`, `toTexture`,
`readPixels()`. `Canvas2DContextAdapter` drives a real canvas in browsers.

## Renderer

`Renderer2D.begin(camera, clearColor)`, `draw(texture, transform, opts)`, `drawLine`,
`drawPolygon`, `drawCircle`, `drawText` (bitmap font), `flush()`. `SpriteBatcher`
packs quads via `createQuadBuffer`.

## Sprites and animation

`SpriteSheet` slices textures into frames; `SpriteAnimator` plays named clips with
frame timing. `Camera2D` pans/zooms with `viewportWidth/Height`.

## Output

`encodePng(pixels)` writes PNG buffers from any `Pixels` view.
