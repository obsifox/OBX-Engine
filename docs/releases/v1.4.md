# OBX Engine v1.4.0 — ObsiFox Studio

**Release date:** 2026-09-27 · **Tag:** `v1.4.0` · **Scope:** editor layer —
developer can create a project, open it in **ObsiFox Studio**, create a scene, add
entities, modify components, import assets, save the scene, run the project, edit
scripts, and debug basic errors (all ten criteria verified in tests and demo).

## Highlights

- **ObsiFox Studio facade** (`studio.ts`): one headless deterministic object wiring the
  editor core (scene document, commands, selection, inspector, console, profiler,
  viewport) with the v1.4 layer (project manager, hierarchy, asset browser, extended
  inspector, script editor, docking, toolbar, status bar, palette, shortcuts,
  preferences, layouts).
- **Project Manager** (`project.ts`): create/open/close projects, scene registry
  (add/remove/rename), settings (nested preference store), recent list, save/markSaved,
  import/export, validation, pluggable storage backend, `ProjectError`.
- **Scene editing**: entity CRUD (undoable) via hierarchy panel, multi-select,
  duplicate subtree with fresh ids (undoable), transform tools (translate/rotate/scale)
  with world/local space, grid + vertex snapping, transform gizmo (geometry, hit-test,
  drag deltas, local-space application, rotation deltas), camera navigate/frame/flyTo.
- **Inspector** (`properties.ts`): primitives, arrays (`path[]`), enums, resources
  (`assignResource`), references (`setReference`), component properties, defaults
  (reset-to-default), validation per node and per value, multi-object editing —
  fully integrated with the command stack.
- **Asset Browser** (`browser.ts`): folder navigation, search, type filter, sort
  (name/size/type/date), preview with metadata, import/reimport/fail reporting,
  drag-drop moves with importer `move` hook, context menus, metadata editor.
- **Editor infrastructure** (`infra.ts`): shortcuts (contexts, `when` guards),
  command palette (fuzzy search, recents), typed preferences (schema validation,
  reset/revert), layout persistence (JSON, versioned, import/export).
- **Script Editor** (`scripteditor.ts`): tabs, edit/reload, cursor, find/replace/replace
  all, tokenizer-based syntax highlighting (keyword/string/comment/number/operator/
  punctuation, configurable color scheme), bracket + unterminated-string diagnostics,
  execution through pluggable runner with duration, error display across tabs.
- **Docking shell** (`shell.ts`): nested split/tabs layout model with focus, split,
  tabify, close, moveTab, maximize/restore, serialize/restore; toolbar (transform
  tools, snapping, play controls) and status bar with named fields.

## Verification

- `npx tsc -b core math … editor … --force` — clean.
- `npx vitest run` — **701 tests / 67 files green** (editor suite: 110 tests / 10
  files — 15 core + 95 new; 64 new tests added this release).
- Demo `examples/v140-demo`: creates project **Neon Valley**, scene `level1`, 5
  entities, 6 component edits, 3 asset imports, saves scene (7 nodes), runs project
  (`run.ok = true`), edits 3 scripts, reproduces and debugs 6 basic errors, duplicates
  subtrees, splits/tabs the layout, hits the translate gizmo (`translate-x`), stores
  the layout — output `frame.png` (studio shell 640×360) + `stats.json`.

## Known gaps (honest)

- Toolbar `Ctrl+P` normalizes equal to `Ctrl+Shift+P` (shortcut normalization quirk).
- Transform gizmo rotate-mode ring visualization falls back to the translate layout
  (rotation editing itself works: `GizmoDelta.rotationZ`, `applyTo` in rotate mode).
- AssetBrowser `search` also matches ancestor folder names.
- LayoutPersistence backs up via the `read`/`write` backend only — no quota handling.
- Script diagnostics cover bracket matching + unterminated strings only.

## Migration

- `PropertyValue` now includes `PropertyValue[]`; `ExtendedPropertyDescriptor.kind`
  widens `PropertyDescriptor.kind` with `array`/`resource`/`reference`.
- `StatusBar.fields()` renamed `list()` (the backing map is `values`).
- No breaking changes to v1.x APIs; all packages locked at **1.4.0**.
