# 3D API

`@obx/rendering` 3D path — `Renderer3D` software rasterizer with materials and lights.

## Meshes

`Mesh` from vertex/index arrays; `importGltf` parses glTF JSON + binary buffers into
meshes. `MeshRenderer` binds mesh + material + transform.

## Materials and lights

`Material` modes `unlit | standard` (PBR-lite: base color, metallic, roughness, emissive).
Lights: `AmbientLight`, `DirectionalLight`, `PointLight`; fog via `Fog` parameters.

## Camera3D

`Camera3D` with `position`, `target`, `fov`, `near/far`; `lookAt`, `worldToScreen`,
`project`. Frustum culling helpers: `Aabb`, `Frustum.fromCamera`.

## Renderer3D

`Renderer3D.begin(camera, options)`, `drawMesh(...)`, `end()` with backface culling,
near-plane clipping and per-frame statistics.
